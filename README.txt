【追加内容】
・3つのパワー表示を個別にタップしてベースパワーをロック／解除
・ロック時は「+」を非表示にして絶対値表示
・ロック時は数字を黄色化
・左上に小さなロックアイコンを表示

・ロックした瞬間の値をベースパワーとして保存

ロック中にパワー表示を再タップ：ロック解除して+0
